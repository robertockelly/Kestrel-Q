# Native sampling

Status: **TASK 3.0 COMPLETE / PASS**

Task 3.0 adds a model-specific scalar C17 boundary:

```text
248,320 complete finite F32 logits
+ immutable Qwen3.8 sampling config
+ caller-owned PCG32 state
-> one canonical token ID + bounded diagnostics + committed next RNG state
```

It does not call the model executor, load a GGUF, access payload, tokenize,
decode text or implement a generation loop. Task 3.1 owns that integration.

## Supported policy

The exact official profile is temperature 1.0, top-k 20 and top-p 0.95.
Characterized overrides retain the same processor set only: finite positive
F32 temperature, top-k `0..248320` and top-p `[0,1]`. Zero top-k disables that
processor; top-p one disables nucleus filtering. No other Transformers
processor or generation option is accepted.

The implementation copies scores into caller scratch, sorts deterministically
by ascending score/ID, preserves top-k threshold ties, applies the pinned
ascending-cumulative top-p equality boundary, then recomputes final scalar F32
softmax in token-ID order. It is built under `/fp:strict`, requires
round-to-nearest and never modifies caller logits.

All 248,320 model logits participate. The 243 model-capacity padding IDs are
not silently suppressed because the official processor path does not suppress
them. If categorical selection chooses ID 248077 or above, selection fails and
neither result nor RNG state changes. EOG IDs 248044/248046 remain eligible;
stopping belongs to Task 3.1.

## RNG

The sampler uses an independently implemented PCG-XSH-RR 64/32 contract based
on Apache-2.0 `pcg-c-basic@bc39cd76ac3d541e618606bcc6e1e5ba5e5e6aa3`.
It links no PCG dependency. Seed and 63-bit stream use the published
set-sequence expansion. One successful selection consumes one word, mapped to
binary64 `word / 2^32`. State format v1 records the internal state, increment,
seed, stream, draw count and an integrity word. Reset/snapshot/import are
explicit and there is no global RNG.

Categorical traversal is ascending token ID with binary64 cumulative mass.
Intervals are half-open; an exact internal boundary selects the following
token. The maximum word remains below one.

## Evidence and results

Pinned Transformers independently generated processor/probability expectations
before native implementation. An independent Python implementation of the
published PCG arithmetic generated RNG and fixed-selection expectations. The
native comparison covers seven calibration and seven disjoint holdout cases.

- processed retained logits: `EXACT_BITS` (calibration and holdout max 0 ULP);
- probabilities: calibration max 1 ULP / `7.450580596923828e-09` absolute;
- frozen probability contract: max 3 ULP and
  `5.960464477539063e-08` absolute;
- holdout probabilities: max 1 ULP / `7.450580596923828e-09` absolute;
- retained IDs, counts, PCG words/state and selected IDs: exact pass;
- two padded-ID selections: exact fail-closed with unchanged RNG;
- interval start, exact half boundary and largest word: exact pass.

The statistical gate was chosen before native execution. It uses 100,000 draws
per case across uniform two-, four- and official-profile nineteen-token
support. A family alpha of 0.001 is enforced with a Hoeffding absolute-frequency
bound and union correction across 25 category assertions. Independent and
native populations pass without treating token-by-token equality as a
distribution test.

## Bounded characterization

Release measurements on KQ-01 are descriptive, not performance guarantees:

- immutable config: 56 bytes;
- caller RNG state: 56 bytes;
- result diagnostics: 56 bytes;
- target-vocabulary scratch: 3,973,127 bytes;
- RNG draws per successful selection: one;
- retained candidates in the synthetic official-default case: 12;
- initial eight-run official-profile selection observation: approximately
  4.875 ms per selection.

No optimization claim follows. The scalar full-vocabulary sort is a correctness
reference, not a final high-throughput sampler.

The final clean KQ-01 Release validation passed 42/42 CPU CTests and 44/44
CUDA-enabled CTests. The CUDA suite retains only the already governed external
NVCC-generated C4211 warning; the new C17 code adds no `/W4` warning. Oracle
assets regenerated byte-identically and native comparison verification passed.

## Failure and transaction boundary

Null/invalid arguments, wrong vocabulary count, unsupported policy fields,
invalid temperature/top-k/top-p, non-finite scores, invalid mass, padded
selection, corrupt/version-mismatched RNG, insufficient scratch, incompatible
FP rounding and overlapping buffers fail explicitly. Work uses a private RNG
copy; state/result commit only after valid canonical-ID selection.

Task 2.12/2.13 greedy argmax remains unchanged and separate. No model payload,
executor/CLI sampling, Python/Transformers/llama.cpp production dependency,
SIMD/CUDA sampling kernel, cache, prefetch or scheduler was added.
